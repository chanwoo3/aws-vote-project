# 학과 축제 인기 공연 투표 서비스

## 서비스 소개
학과 축제 공지 직후 학생들의 투표 요청이 집중되는 상황을 가정한 Flask 웹서비스입니다.

## 사용자 기능
1. 공연 선택 후 투표하기
2. 공연별 득표수 결과 확인
3. 새 공연 항목 추가

## 로컬 실행
```bash
docker compose up -d --build
```
브라우저: http://localhost:8080
상태 확인: http://localhost:8080/api/health

## AWS 배포 구성
브라우저 → EC2(8080 포트) → Docker 컨테이너(Flask 5000 포트) → SQLite(영구 볼륨)

EC2 한 대로 과제 규모의 요청을 처리하도록 구성했습니다. ELB 및 Auto Scaling은 추가 비용과 구성 복잡성을 고려하여 사용하지 않습니다. 실제 부하 측정 결과는 별도로 기록합니다.
