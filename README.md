# 축제 공연 투표 웹사이트

## 1. 프로젝트 소개

축제에서 진행되는 공연 정보를 확인하고 원하는 공연에 투표할 수 있는
웹서비스입니다. 축제 기간처럼 특정 시간에 이용자가 집중될 수 있는 상황을
고려하여 제작했습니다.

-   **대상 사용자:** 축제 참가자 및 공연 관람객
-   **해결하려는 문제:** 여러 공연에 대한 선호도를 한곳에서 확인하고,
    투표 결과와 응원 의견을 쉽게 공유할 수 있도록 합니다.
-   **주요 기능**
    1.  메인 화면에서 축제 및 공연별 투표 현황 확인
    2.  공연 목록 조회 및 투표
    3.  공연 상세 정보 조회
    4.  공연별 투표 결과 및 순위 확인
    5.  응원 게시글 작성 및 비밀번호를 이용한 삭제
    6.  공연 정보 추가·수정·삭제 및 관리자 비밀번호 확인

## 2. 사용 기술 및 AWS 구성

### 사용 기술

  구분                    기술                    역할

### AWS 구성 및 사용자 요청 경로

``` text
사용자 웹 브라우저
       |
       | HTTP :8080
       v
AWS EC2 인스턴스
       |
       | Docker 포트 연결 (8080 -> 5000)
       v
Flask 컨테이너
       |
       v
SQLite 데이터베이스
(Docker 볼륨에 데이터 저장)
```

사용자가 브라우저에서 EC2 퍼블릭 IP의 8080 포트로 접속하면 EC2에서 실행
중인 Docker 컨테이너의 Flask 애플리케이션이 요청을 처리합니다. 공연 및
투표 데이터는 SQLite에 저장하며 Docker 볼륨을 사용해 컨테이너를 다시
실행해도 데이터가 유지되도록 구성했습니다.

**AWS 서비스를 선택한 이유:** 기존 Flask 및 Docker Compose 프로젝트를
가상 서버에서 실행하기 쉽고, 보안 그룹을 통해 외부 접속 포트를 관리할 수
있어 EC2를 선택했습니다.

### ELB 및 Auto Scaling 적용 여부

이번 프로젝트는 과제 기능을 구현하고 배포하는 것을 목표로 EC2 단일
인스턴스를 사용했습니다. 예상 규모가 크지 않고 추가 서비스 비용과 구성
복잡성을 줄이기 위해 ELB와 Auto Scaling은 적용하지 않았습니다.

향후 축제 기간에 접속자가 크게 증가하면 ELB로 여러 서버에 요청을
분산하고, Auto Scaling으로 부하에 따라 서버 수를 조절하는 방안을 고려할
수 있습니다.

## 3. 실행 및 배포 방법

### 준비 사항

-   Python 3.12 환경
-   Docker 및 Docker Compose
-   Git
-   AWS 계정 및 실행 중인 EC2 인스턴스

### 로컬 실행

프로젝트 저장소를 내려받습니다.

``` bash
git clone https://github.com/chanwoo3/aws-vote-project.git
cd aws-vote-project
```

프로젝트 루트에 `.env` 파일을 만들고 아래 환경 변수를 설정합니다.

``` env
ADMIN_PASSWORD=관리자비밀번호
SECRET_KEY=충분히_긴_임의의_비밀키
```

Docker Compose로 빌드하고 실행합니다.

``` bash
docker compose up -d --build
```

실행 상태와 헬스 체크를 확인합니다.

``` bash
docker compose ps
curl http://localhost:8080/api/health
```

브라우저에서 아래 주소로 접속합니다.

``` text
http://localhost:8080
```

종료할 때는 다음 명령어를 사용합니다.

``` bash
docker compose down
```

> 투표 및 게시글 데이터가 저장된 볼륨을 보존하려면
> `docker compose down -v` 명령어를 사용하지 않습니다. `.env` 파일에는
> 비밀번호와 비밀키가 있으므로 GitHub에 업로드하지 않습니다.

### AWS EC2 배포

1.  AWS 콘솔에서 EC2 인스턴스를 생성하거나 기존 인스턴스를 실행합니다.
2.  EC2에 접속한 뒤 GitHub 저장소를 내려받습니다.
3.  프로젝트 루트에 `.env` 파일을 생성하고 `ADMIN_PASSWORD`,
    `SECRET_KEY`를 설정합니다.
4.  아래 명령어로 애플리케이션을 빌드하고 실행합니다.

``` bash
git clone https://github.com/chanwoo3/aws-vote-project.git
cd aws-vote-project
sudo docker compose up -d --build
```

이미 프로젝트가 내려받아져 있다면 프로젝트 폴더에서 다음 명령어를
실행합니다.

``` bash
git pull origin main
sudo docker compose up -d --build
```

5.  EC2 보안 그룹의 인바운드 규칙에서 TCP 8080 포트를 허용합니다.
6.  브라우저에서 다음 주소로 접속합니다.

``` text
http://<EC2 퍼블릭 IPv4 주소>:8080
```

### 포트 및 접속 정보

  항목                  값
  --------------------- --------------------------------------
  외부 접속 포트        8080
  Flask 컨테이너 포트   5000
  Docker 포트 연결      8080:5000
  배포 주소             `http://<EC2 퍼블릭 IPv4 주소>:8080`
  헬스 체크             `/api/health`
