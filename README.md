# Campus Festival 투표 서비스

Flask + SQLite + Docker Compose 기반 축제 공연 투표 웹사이트입니다.

## 기능 및 페이지
- `/` 홈: 총 투표수, 현재 1위, 인기 공연
- `/vote` 공연 검색 및 투표 (브라우저 세션별 중복 방지)
- `/performance/<id>` 공연 상세 및 최근 응원 글
- `/results` 순위 및 득표율 그래프
- `/board` 응원 글 등록/조회/비밀번호 삭제
- `/manage` 공연 추가, 관리자 비밀번호 확인 후 수정/삭제
- `/api/health` 상태 확인

## 실행
1. `.env.example`을 `.env`로 복사하고 관리자 비밀번호와 랜덤 `SECRET_KEY`를 입력합니다.
2. `docker compose up -d --build`
3. `http://localhost:8080` 접속

## 기존 데이터 마이그레이션
기존 `votes` 테이블을 유지하면서 `description` 열과 `cheers` 테이블을 자동 생성합니다.
**같은 Docker Compose 프로젝트명과 볼륨을 사용해야 기존 데이터가 유지됩니다.**

## 보안 및 제약
- 응원 글 삭제 비밀번호는 해시로 저장합니다.
- 관리자 비밀번호는 환경변수에서 읽으며 로그인 기능은 없습니다.
- Flask 세션 기반 중복 투표 방지는 브라우저/쿠키 수준이며 완전한 부정 투표 방지책은 아닙니다.
- HTTP 공개 접속 시 관리자 비밀번호와 게시글 삭제 비밀번호를 입력하지 마세요. HTTPS를 구성해야 합니다.
- 강한 인증, CSRF 방어, 속도 제한, 운영용 WSGI 서버는 실제 서비스 배포 전 추가가 필요합니다.
- ELB/Auto Scaling 다중 인스턴스 환경에서는 SQLite 공유 저장소와 세션 기반 투표 제한을 재설계해야 합니다.
